## 本次修正

- 两个 Skill 补充回环网络与后台进程权限说明，权限拒绝时走宿主审批，不反复初始化或重启正常服务。
- CLI 源码在 `EACCES` / `EPERM` 时保留可操作的诊断，不改变其他连接错误的行为。
- 包元数据补充实际 GitHub 仓库、主页和问题反馈链接。
- Release 草稿准备流程与 npm 发布许可分开：GitHub 打包不再要求打开 npm 发布开关。

## 范围与后续

这是源码公开前的本机审查和自动检查，不是独立渗透测试，也不能保证没有未知漏洞。敏感信息检查基于列出的模式、已知本机凭证和文件路径，并非外部专业扫描服务。
